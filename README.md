# わり算の筆算道場

小学4年生向け、わり算の筆算を工程ごとに練習するアプリ。
HTML 1ファイルで動きます（ビルド不要・オフライン可）。

`warizan-hissan.html` をブラウザで開くだけで使えます。

## できること

- **2桁 ÷ 1桁・あまりなし・商が2桁** の問題を自動出題（全92通り）
- 「たてる → かける → ひく → おろす → たてる → かける → ひく」の
  **7工程を1マスずつ入力**。今どの工程かをチップで示し、書き込むマスが光る
- 間違えたマスはその場で赤く揺れて消える（正しい数字だけが残る）
- ノーミスなら**花丸**、ミスありなら丸
- **きろく**：といた数／花丸／連続記録と、**どの工程でつまずいたかの内訳**
  （たてる・かける・ひく・おろす別）。端末内（localStorage）に保存
- テンキー・物理キーボードの両方で入力可
- 明るい画面は方眼ノート、暗い画面は黒板の配色に自動で切り替わる

## 現在の仕様上の前提

以下は教科書によって流儀が分かれるところ。変更する場合はここを見直す。

1. **ひき算の答えが0でも書かせる。**
   例: 63÷3 は十の位を引いたあと「0」を書き、3をおろして「03」にする。
   東京書籍・啓林館系の書き方。
2. **商に0が立つ問題（60÷3=20 など）は除外。** 手順は同じだが、
   つまずきポイントとしては別なので練習セットを分ける想定。
3. **数字を書く位置はアプリが決める。** 2回目のかけ算が2桁か1桁かを
   判定してマスを光らせる。「どの位に書くか」を子どもに選ばせるのは
   3桁÷1桁に広げる段階から。

## これから広げる順（案）

1. あまりあり
2. 商が1桁になる場合（36÷4 など）
3. 商に0が立つ場合
4. 3桁÷1桁 → 2桁で割る（ここで「商をどの位に立てるか」を問う）
