# わり算の筆算道場

小学4年生向け、わり算の筆算を工程ごとに練習するアプリ。
HTML 1ファイルで動きます（ビルド不要・オフライン可）。

- 公開URL: https://watarusora.github.io/warizan-hissan/
- ローカルで使う場合は `warizan-hissan.html` をブラウザで開くだけ

## もんだいの種類

画面上部のボタンから、3つの軸を選びます（選択は端末に保存）。
まん中の軸は、わる数のけた数によって中身が変わります。

### わる数が1けた（2桁 ÷ 1桁）

| 商の形 | あまりなし | あまりあり |
|---|---|---|
| **商2けた**（十の位から商が立つ） | 92通り | 208通り |
| **商1けた**（十の位には立たない） | 58通り | 302通り |
| **商に0**（一の位に0が立つ） | 14通り | 46通り |

合計720通り＝**わる数2〜9 × わられる数10〜99 の全パターン**。

### わる数が2けた

| もんだいの形 | あまりなし | あまりあり |
|---|---|---|
| **何十でわる**（240÷60 など・導入用） | 268通り | 7,832通り |
| **わられる数2けた**（84÷21 など） | 106通り | 1,534通り |
| **わられる数3けた**（352÷15 など） | 2,104通り | 76,446通り |

合計88,290通り。数が多いので全列挙せず、その場で作っています。
**商が1にしかならない問題（98÷73 など）は出しません。**
見当をつける練習にならないためです。

それぞれ「まぜる」も選べます。初期値は「商2けた・あまりなし」。
まぜたときは種類が均等になるよう調整し、同じ種類が続きすぎないようにしています。

## できること

- 「たてる → かける → ひく → おろす」の**工程を1マスずつ入力**。
  今どの工程かをチップで示し、書き込むマスが光る
  （商1けたのときは「たてる → かける → ひく」の3工程で終わる）
- **商を立てる位を子どもに選ばせる**（商1けた・まぜるのとき）。
  十の位と一の位が点線で示され、タップして選んでから数字を入力する
- あまりが出たら、筆算の最後の数に「あまり」のふだが付き、
  答えも「14 ÷ 9 = 1 あまり 5」の形で示す
- **わられないときは0を立てる**ことを、その場面で教える
- わる数が2けたのときは、**わる数を何十とみて見当をつける**やり方を示す
  （「15 を およそ 20 とみて、35 ÷ 20 で見当をつけよう。合わなければ 1つずつ直すよ」）
- **まちがいの種類に応じて理由を返す**（すべて、その問題の実際の数で）

  | まちがい | 返すことば |
  |---|---|
  | 商が大きすぎる | 大きすぎるよ。2 × 5 = 10 で、9 より大きいね |
  | 商が小さすぎる | 小さすぎるよ。ひいたあとが まだ 5 でわれてしまうね |
  | あまりがわる数以上 | あまりは わる数の 5 より小さくなるはずだよ |
  | 立てる位が違う | 十の位の 3 は 8 より小さいね。十の位に商は立たないよ |
  | 0を立てる場面 | 1 は 7 でわれないね。わられないときは 0 を立てるよ |

  商が大きすぎ・小さすぎのときは「1つ小さくしてみよう」「1つ大きくしてみよう」
  と続けます。わる数が2けたのときの仮商の直し方そのものです。

- 間違えたマスはその場で赤く揺れて消える（正しい数字だけが残る）
- ノーミスなら**花丸**、ミスありなら丸
- **きろく**：といた数／花丸／連続記録と、**つまずいた内訳**
  （たてる・かける・ひく・おろす・**立てる位**・**0を立てる**）。
  端末内（localStorage）に保存
- テンキー・物理キーボードの両方で入力可（位を選ぶ場面では ← → キーも使える）
- 明るい画面は方眼ノート、暗い画面は黒板の配色に自動で切り替わる

## 画面の向き

**iPadを横向きにすると、テンキーが筆算の右側に出る2カラムになります。**
縦向きは今まで通りの1列。切りかえは画面の向きだけで自動、設定はいりません。

横向きでは画面の高さに合わせて筆算とテンキーを大きくするので、
横にしたときの方がマス目も数字も大きく、押しやすくなります。

| 画面 | 向き | 段組み | マスの大きさ | スクロール |
|---|---|---|---|---|
| iPad 1080×810 | 横 | 2カラム | 75px | なし |
| iPad 1024×768 | 横 | 2カラム | 71px | なし |
| iPad Pro 1194×834 / 1366×1024 | 横 | 2カラム | 76px | なし |
| iPad 810×1080 | 縦 | 1列 | 58px | なし |
| iPhone 844×390 | 横 | 2カラム | 27px | なし |
| iPhone 430×932 | 縦 | 1列 | 50px | なし |

小さめのiPhone（375×667 など）を縦にした場合だけ、
高さが足りずスクロールが残ります。

実装は `.body / .colA / .colB` という入れ物を用意し、
縦向きでは `display:contents` で消して1列に、
横向き（`orientation:landscape` かつ幅760px以上）では
flexの2カラムに切りかえています。HTMLの並び順は1つだけです。

## 現在の仕様上の前提

以下は教科書によって流儀が分かれるところ。変更する場合はここを見直す。

1. **ひき算の答えが0でも書かせる。**
   例: 63÷3 は十の位を引いたあと「0」を書き、3をおろして「03」にする。
   東京書籍・啓林館系の書き方。
2. **商に0が立つときも、かけ算・ひき算を省略せずに書かせる。**
   例: 71÷7 は一の位に0を立てたあと、0×7=0 と 1−0=1 も書く。
   教科書によっては「かんたんな筆算のしかた」として省略を教えるので、
   そちらに合わせたい場合はここを変える。
3. **「商2けた」だけを選んでいるときは、書く位置をアプリが決める。**
   位の判断が問題にならないので、テンポを優先している。
   商1けたが出うる設定では、最初の商だけ位を選ばせる。
   2回目以降のかけ算・ひき算の位取りは今もアプリが決めている。

## つくりの話：けた数によらない筆算エンジン

2桁で割る形に広げるとき、筆算のマスを固定（3列×6行）から可変にした。
いまは わられる数・わる数のけた数から、次を計算して組み立てている。

- 最初にわる部分 … 先頭 dw けた。それでも わる数より小さければ dw+1 けた
- 段の数 … わられる数のけた数 − 最初にわる部分 + 1
- 行数 … 2 + 段の数 × 2、列数 … わる数のけた数 + わられる数のけた数

工程（たてる→かける→ひく→おろす）も段ごとに生成するので、
1けたでも2けたでも同じ道を通る。3けた÷1けたや、
わる数3けたに広げるときも、出題の範囲を足すだけで済むはず。
